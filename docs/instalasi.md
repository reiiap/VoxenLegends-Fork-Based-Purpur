# Instalasi

Server belum boleh dipasang sebelum `buildVersion -PmcVersion=1.21` berhasil dan artifact tervalidasi. Setelah itu, buat direktori server terpisah, salin artifact Voxen hasil build ke sana, dan jalankan dengan JDK 21 sesuai dokumentasi Purpur.

Persetujuan EULA adalah tanggung jawab operator. Jangan commit `eula.txt` atau konfigurasi server produksi ke repository ini.
